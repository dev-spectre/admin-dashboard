# Admin Dashboard

A responsive admin dashboard UI built with pure HTML and CSS.

## Overview

A clean, modern admin dashboard interface featuring a sidebar navigation, task management, messaging, and user profile sections. Built as a front-end practice project with pixel-perfect responsive design.

## Features

- Responsive sidebar navigation
- Task management panel
- Messages/notifications area
- User profile section
- Clean, modern UI with SVG icons

## Tech Stack

- **HTML5** — semantic markup
- **CSS3** — custom properties, flexbox, grid
- **SVG** — inline icons

## Getting Started

Open `index.html` in a browser. No build step required.

## Project Structure

```
├── index.html           # Main dashboard page
└── assets/
    ├── icons/           # SVG icons
    └── img/             # Screenshots and images
```
